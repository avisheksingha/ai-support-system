# AI Support System V2.1 Release

**Release Name:** Production Hardening & Dashboard Release
**Version:** 2.1.0
**Status:** Released
**Compatibility:** Spring Boot 4x, React 18, Vite

---

## 1. Overview

Version 2.1.0 focuses on bringing the V2.0 Orchestrator architecture to life through a rich administrative interface, expanding domain capabilities, and solidifying the platform's security and testing posture.

While V2.0 laid the backend foundation for Agentic Orchestration, V2.1.0 delivers the tools required for operators to monitor, manage, and augment that system.

## 2. Key Features & Additions

### Administrative Dashboard (`ai-support-dashboard`)

- **System Analytics:** New `AdminDashboardService` providing real-time overview metrics (avg latency, ticket volume, autonomous resolution rates).
- **Workspace Visualization:** Added `RoutingPanel` and `TicketDetailView` to monitor real-time AI orchestration outcomes.
- **TanStack Query Integration:** Implemented robust customer ticket hooks for fetching, creating, and messaging tickets.

### Knowledge Base Management System

- **RAG Content Management:** Full CRUD REST APIs implemented in the `rag-service` for managing knowledge articles.
- **Vector Indexing & Metadata:** Enhanced `KnowledgeEmbeddingService` with document chunking, automated pgvector indexing, and robust metadata synchronization.
- **Retrieval Diagnostics:** Added metadata-aware RAG retrieval strategies with explicit debugging outputs for tracing vector match relevance.

### AI Domain Expansion

- **Writing Assistant:** Added `WritingAssistantController` in the `ai-analysis-service` to provide ad-hoc AI text improvement capabilities to frontend agents.
- **System-Wide Categories:** Initialized deterministic `routing_rules` spanning system-wide incident and support categorizations.

## 3. Architecture & Infrastructure Hardening

- **Configuration Centralization:** Refactored properties to use `spring.config.import`, centralizing Actuator and OpenAPI configurations into the `common-library`.
- **Governance Metrics:** Implemented `GovernanceService` to monitor AI execution metrics and policy enforcement in real-time.
- **Documentation Overhaul:** Thoroughly updated `.github/agents` and `docs/architecture` to reflect the V1 Orchestrator freeze, formally deprecating old choreography planning documents.

## 4. Security & Testing

- **Security Patches:** Resolved critical frontend dependencies (bumped `brace-expansion` and `fast-uri`).
- **CSRF Hardening:** Addressed CodeQL vulnerabilities by implementing defense-in-depth CSRF filters and custom stateless exceptions.
- **End-to-End Testing:**
  - Added robust authentication flow tests with mocked API responses.
  - Implemented unit tests for the RAG service, analysis processing, and knowledge embedding lifecycle.

## 5. Upgrade Path

This is a minor, non-breaking release.

- **Backend:** Safe to deploy over v2.0.0. No manual database migrations are required (`auto-ddl` remains supported for local environments).
- **Frontend:** Upgrade package dependencies via `npm ci` due to the React Router v8 bump and security resolutions.

## 6. Known Limitations & Next Steps

The following capabilities are intentionally deferred for future releases (V2.2/V3.0):

- **WebSocket/SSE Integration:** The dashboard currently fetches metrics via TanStack Query polling. Real-time streaming of AI orchestration events via WebSockets is deferred.
- **Semantic Caching:** A caching layer for LLM responses to reduce latency and API costs on duplicate queries is still pending.
- **Multi-Agent Swarm:** Intelligent routing of complex tasks between specialized sub-agents (e.g., delegating a code issue to a distinct CodeAgent while handling billing with a BillingAgent) remains in the V3 roadmap.
